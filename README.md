# Система автоматизации бронирования аудиторий и оборудования

Веб-приложение предназначено для планирования, учета и контроля использования аудиторного фонда и
материально-технического оснащения учебного или иного заведения. Система предотвращает конфликты при бронировании
ресурсов, автоматизирует процесс согласования и предоставляет инструменты аналитической отчетности.

## Реализованные возможности

* Подбор свободных ресурсов: динамический поиск аудиторий и оборудования с фильтрацией по вместимости, типу и статусу с
  исключением уже забронированных объектов на выбранное время.
* Управление заявками: создание разовых заявок и формирование групповых бронирований (серий) через календарный интерфейс
  с возможностью разрешения конфликтов для отдельных дат.
* Процесс согласования: механизм автоматического одобрения типовых заявок и ручное рассмотрение сложных запросов.
  Реализована блокировка заявки при рассмотрении одним из согласующих для предотвращения дублирования действий.
* Формирование документов: автоматическая генерация PDF-документов, подтверждающих бронирование, с фиксацией факта
  подписания.
* Аналитика и отчетность: расчет ключевых показателей использования ресурсов, построение графиков распределения нагрузки
  и экспорт отчетов в форматах PDF и CSV.
* Уведомления: система внутренних оповещений пользователей о смене статусов заявок и новых комментариях.

## Ролевая модель

Система работает в закрытом контуре (самостоятельная регистрация недоступна) и поддерживает три типа учетных записей:

1. Инициатор (преподаватель, диспетчер) — создание заявок, мониторинг их статусов, выгрузка подтверждающих документов.
2. Согласующий (сотрудник учебного отдела, деканата) — рассмотрение заявок, вынесение решений, просмотр аналитики
   загруженности фонда.
3. Администратор (оператор системы) — ведение справочников (аудитории, оборудование), управление учетными записями,
   доступ к системной отчетности.

## Стек технологий

* Backend: Python, Django, Django REST Framework.
* Frontend: HTML/CSS (Django Templates), Vanilla JavaScript, Chart.js.
* База данных: SQLite (для разработки), PostgreSQL (рекомендуется для рабочей среды).
* Формирование файлов: ReportLab (PDF-документы), Matplotlib (серверная генерация графиков).

## Инструкция по развертыванию и запуску

1. Клонируйте репозиторий на локальную машину и перейдите в директорию проекта.

2. Создайте и активируйте виртуальное окружение:
   ```shell
   python -m venv .venv
   ```
   Для Windows:
   ```shell
   .venv\Scripts\activate
   ```

   Для Linux/macOS:
   ```shell
   source .venv/bin/activate
   ```

3. Установите зависимости проекта:
   ```shell
   pip install -r requirements.txt
   ```

4. Примените миграции для создания структуры базы данных:

   ```shell 
   python manage.py migrate
   ```

5. Создайте и загрузите начальные данные (фикстуры) со справочниками и тестовыми пользователями:
   
   - Готовый скрипт для создания фикстур (данные могут быть не совсем корректны и неверно отражать предметную область)
   ```shell
   python makedata.py
   ```
   - Применение фикстур
   ```shell
   python manage.py loaddata initial_data.json
   ```

6. Запустите локальный сервер разработки:
   ```shell
   python manage.py runserver
   ```

Приложение будет доступно по адресу: http://127.0.0.1:8000/

Важные замечания по безопасности и работе с пользователями:

* При первом входе в систему по временному паролю приложение в обязательном порядке потребует его изменить.
* При создании новой учетной записи администратором пароль генерируется автоматически и отправляется пользователю на
  указанный email.
* В режиме разработки (DEBUG = True) отправка писем перенаправлена в файловую систему. Письма с паролями для новых
  пользователей сохраняются в формате текстовых файлов в директорию `email/` в корне проекта.
